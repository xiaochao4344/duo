# iPhone 16 中文舞台

私有制片工程。一台按 iPhone 16 直板布局复刻的中文手机界面,用于《日常怪谈》系列短剧的界面拍摄与剧本创作:剧本里要出现的手机画面,都在这里逐帧驱动、截图或录屏,不依赖真机。

仓库后续会混入大量剧本与分镜内容,**必须保持私有,不要公开、不要 fork 到公开网络**。

## 已经做好的部分

- **iPhone 16 壳层**:横向状态栏(左时间、中灵动岛 126x37、右信号/WiFi/电池)、底部四图标 Dock、满高图标网格,已去除原项目的折叠屏特性。
- **系统文字全中文**:锁屏日期、控制中心(含网络行与专注模式)、关机页、通知清除、新建文件夹默认名等。
- **系统键盘**:点任意输入框弹起,iOS 布局;拼音面带组字串与候选条(内置拼音切分与常用词候选)、英文面、数字符号面;App 自动让出键盘高度。
- **可操作界面(全部代码绘制,数据为内置中文阵容)**:
  - 微信:会话列表、单聊与群聊页、通讯录、发现、我,绿气泡 #95EC69,可发送带回复
  - 百度地图:代码绘制的街区地图、附近列表、路线页(驾车/公交/步行)
  - TP-Link Tapo:摄像头卡片、实时画面(时间戳水印)、云台、侦测事件回放
  - 电话:拨号键盘、最近通话、个人收藏、语音留言(中文转写)
  - 信息:中文会话与联系人,跨 App 人名号码一致
  - 通讯录:中文名单,按拼音首字母分组

## 运行(制片平板模式)

制片不用 3D 折叠场景,用仓库根目录的 flat 入口把系统直挂到 393x852 直板屏:

```sh
bun install
bun run flat-serve.ts        # 默认端口见 FLAT_PORT,页面即整台手机
```

深链接直达单个 App:`?app=WeChat`、`?app=Messages`、`?app=Tapo`、`?app=BaiduMap` 等,方便逐场拍摄。

改任何像素前先读 `DESIGN.md`;仓库约定见 `AGENTS.md`(禁用 em dash、完工跑 `bun run typecheck`、不擅自加依赖)。

## 结构速记

```
packages/shell/     壳层:状态栏、主屏、锁屏、控制中心、键盘召唤层(springboard/)
packages/uikit/     组件与图标;keyboard.tsx + pinyin.ts 是系统键盘
packages/apps/      每个 App 一个包;wechat/、baidu-map/、tapo/ 为本工程自建
flat/               制片平板入口(flat.html / flat.ts)
```
